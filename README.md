# Colors Web Application

<strong>This Colors web application</strong> allows users to log in with a valid username and password. They will be notified if their login is invalid. Once logged in, they can add colors. A confirmation message will show, and the color will be stored to the user's account. They can also search for colors, which will be displayed. The user is also able to log out.

Technologies Used:
This web application was created using the LAMP Stack: Linux as the operating system, Apache as the HTTP server, MySQL as the database to store user logins and colors, and PHP as the programming language to implement the API.

Setup Instructions: 
Run this application on a DigitalOcean Droplet running LAMP on Ubuntu 24.04. Purchase a domain name to point to the server's IP address. Structure the folders in the Droplet to match this repository's, and upload all the files to the remote server. Create the MySQL database. Then, create tables to store users and colors. Populate working data rows with users and colors. Create a user to run queries against MySQL.

How to Run and Access the Application: 
Access the COLORS web application through the domain name connected to the server's IP address. The login page should be displayed. Enter credentials to access the application; add and search for colors.

Assumptions and Limitations: 
A Linux-based server running the LAMP stack is required to run this program. A private server Droplet and domain name must also be purchased.
